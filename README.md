# see you

打包源码与APK存档仓库 - 按编号顺序存放每次构建产物。

## 仓库结构

```
see-you/
├── 01/          # 第1次打包
│   ├── source/  # 未编译的原始源码
│   └── apk/     # 编译好的APK安装包
├── 02/          # 第2次打包
│   ├── source/
│   └── apk/
├── 03/          # 第3次打包
│   ├── source/
│   └── apk/
└── ...
```

## 说明

- 每次打包后会创建下一个编号文件夹（01、02、03...）
- 每个编号文件夹内包含：
  - source/ — 未编译的原始源码文件
  - apk/ — 编译好的APK安装包（Debug / Release）
- 源码来源于 lhc8055/fy 仓库
- APK通过 GitHub Actions 自动构建
